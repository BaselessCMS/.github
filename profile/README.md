# Baseless

I am a long-time WordPress developer that tried Bludit CMS out of curiosity. I found room for improvement in the theme and plugins offered on the Bludit website so I began experimenting with the platform, deciphering code as there is little documentation provided by the code authors.

Here are the products that have resulted from said work. They were all developed to be used together, under the Configure 8 theme platform, but they can be used with other themes and plugin configurations.

Also in development, slowly, is a CMS divergent from Bludit, which I am calling Baseless. Do not develop expectations for this CMS but it may become something useful.

Built by [Controlled Chaos](https://github.com/ControlledChaos/).
